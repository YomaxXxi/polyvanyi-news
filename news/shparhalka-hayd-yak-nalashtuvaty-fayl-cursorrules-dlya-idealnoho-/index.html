Покрокова інструкція:

1. Створіть файл з назвою .cursorrules у корені вашого репозиторію.

# AI Development Rules
  • Never remove existing comments unless explicitly requested.
  • Always use strict typing (TypeScript/Python type hints). No 'any'.
  • Follow clean architecture and DRY principles.
  • Do not use deprecated APIs, libraries, or patterns.
  • Write self-documenting code with meaningful variable names.
  • Keep functions small and focused on a single responsibility.
  • Add JSDoc/docstrings for all public functions and classes.
  • When refactoring, explain what and why you are changing.
  • Double-check edge cases before generating the final code block.

Секрети та підводні камені:

Не пишіть занадто роздуті правила на 500 рядків — ШІ почне ігнорувати частину інструкцій. Фокусуйтеся на 5-7 ключових обмеженнях вашого технологічного стека.

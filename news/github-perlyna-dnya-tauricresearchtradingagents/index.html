TauricResearch/TradingAgents

Відкрити репозиторій

У чому суть: Потужний фреймворк на базі мультиагентних LLM для фінансового трейдингу, який моделює роботу команд аналітиків та менеджерів за допомогою штучного інтелекту.

  • Ключові фішки:

▫️ Паралельна робота агентів-аналітиків для максимально швидкого та глибокого опрацювання ринкових даних.

Реклама

▫️ Гнучке налаштування провайдерів під кожен шар моделі: менеджер та аналітики можуть працювати на різних LLM.

▫️ Вбудований бектестинг, що опирається виключно на історичні дані, опубліковані на момент прийняття рішення.

🛠 Для кого / Як спробувати: Ідеально для Quant-розробників та фінтех-ентузіастів, які прагнуть автоматизувати аналіз ринку. Запуск через клонування репозиторію та інсталяцію залежностей у Python-оточенні.

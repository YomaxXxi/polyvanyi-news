Культова Nokia 6300 отримала неможливий ШІ-апгрейд: як застарілий кнопковий девайс подрувили з ChatGPT та Claude

Михайло Поливаний · 27 жовтня 2026 · 2 хв читання

Майже 20 років тому світ побачив Nokia 6300 — легендарний «тупий телефон», що завоював мільйони сердець завдяки витонченому металевому корпусу та доступній ціні. У 2026 році оригінальна модель майже втратила актуальність через вимкнення 2G-мереж та застарілий браузер із підтримкою лише TLS 1.0. Проте турецький розробник Емір Каршіякалі знайшов геніальне рішення, створивши додаток Aikon (Nokia навпаки) для запуску сучасних нейромереж на старій платформі S40.

Реклама

Ключові характеристики проекту:

  • 📱 Пристрій: Nokia 6300 (оригінальна версія 2007 року)
  • ⚡️ Програмна база: платформа Nokia Series 40 + Java (J2ME)
  • 🧠 ШІ-інтеграція: ChatGPT, Claude, Gemini та Grok через API
  • 💻 Бекенд-сервер: проміжний сервер на Go для обробки запитів
  • 📦 Обмеження зв'язку: пакети даних по 8 КБ для сумісності з пам'яттю телефону
  • 💵 Вартість: безплатно (потрібні власні API-ключі та білінг нейромереж)
  • Архітектура рішення: Оскільки мобільний браузер Nokia не підтримує сучасні протоколи безпеки та не здатен відрендерити вебсторінки, мобільний клієнт на Java спілкується через спеціальний бекенд на мові Go. Сервер приймає запити від користувача, зв'язується з великими мовними моделями та стискає відповіді до крихітних блоків по 8 КБ, які застарілий процесор та екран здатні відобразити.

Універсальність клієнта: Спочатку програма підтримувала лише експериментальний зв'язок з Claude, але згодом автор розширив її можливості на всі провідні чат-боти ринку, перетворивши ретро-девайс на мініатюрний текстовий термінал доступу до штучного інтелекту.

💡 Думка редакції: Цей проєкт чудово демонструє, як ентузіазм та інженерна кмітливість здатні дати друге життя легендарному залізу, яке ніколи не проєктувалося під епоху хмарних нейромереж. Звісно, користуватися цим щодня не надто практично, але сам факт появи ChatGPT у кнопковій трубці з 2007 року вражає.

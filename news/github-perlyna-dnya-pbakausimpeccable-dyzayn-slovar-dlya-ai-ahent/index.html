GitHub-перлина дня: pbakaus/impeccable — дизайн-словар для AI-агентів, що рятує від однакового «AI slop» інтерфейсів

Михайло Поливаний · 31 жовтня 2026 · 2 хв читання

Open Source Офіційний репозиторій на GitHub

pbakaus/impeccable

Відкрити репозиторій

Втомилися від того, що всі AI-агенти пишуть код з однаковими фіолетово-синіми градієнтами, картками в картках та шрифтом Inter? Проєкт Impeccable дає вашому штучному інтелекту «дизайн-словник», перетворюючи розмиті запити на кшталт «зробіть гарно» на чіткі інструкції з полірування інтерфейсу.

💡 У чому суть та яку проблему вирішує:

Він замінює дорогі дизайн-консультації та ручне переписування однотипного коду, змушуючи Claude Code, Cursor чи Copilot створювати унікальні, вивірені за UX та стилем вебсторінки замість шаблонного «AI slop».

Реклама

Архітектура та можливості:

  • 🧠 Основний стек / рушій: Rust, Node.js CLI
  • ⚡️ Швидкодія та ресурси: Миттєва генерація правил, нульовий оверхед
  • 🛡 Приватність: 100% Self-Hosted / Local-first (файли стилів живуть у вашому репо)
  • 🔌 Інтерфейси: CLI, npm-пакет, інтеграція з агентами
  • 📦 Сумісність: Cursor, Claude Code, Copilot, Devin та ще 15+ агентів

КЛЮЧОВІ КІЛЕР-ФІШКИ:

  • Спрямування з поліруванням: Команди на кшталт /impeccable bolder активують спеціальні плейбуки для точкового покращення елементів.
  • Автоматичний аудит (critique): ШІ сканує код на відповідність евристикам юзабіліті та ранжує баги й проблеми дизайну перед деплоєм.
  • Боротьба з шаблонами: Назавжди відучує моделі від використання заїжджених трендів і сірої палітри на кольоровому тлі.
  • Гнучкі плейбуки: Можливість створювати власні словники дизайну під бренд-гайдлайни вашої компанії.

Як протестувати за 1 хвилину:

Команда для швидкого запуску локально:

npx impeccable install

Мінімальні вимоги: Node.js, підтримуваний AI-агент у проєкті

🎯 Думка редакції: Абсолютний мегахіт для фронтендерів. Якщо ви активно використовуєте AI для кодингу і втомилися від «штучного» почерку моделей, цей інструмент має бути у кожному проєкті вже сьогодні.

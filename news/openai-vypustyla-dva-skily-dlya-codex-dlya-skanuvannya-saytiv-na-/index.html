OpenAI випустила два скіли для Codex для сканування сайтів на застарілі та небезпечні версії PHP

Михайло Поливаний · 23 жовтня 2026 · 2 хв читання

Компанія OpenAI розширила можливості свого ШІ-асистента Codex, випустивши спеціалізовані скіли для безпеки. Новий інструмент створений спеціально для того, щоб в автоматичному режимі виявляти сайти, які працюють на застарілих і критично вразливих версіях PHP.

Реклама

Ключові характеристики рішення:

  • 🤖 Інструмент: OpenAI Codex Skill
  • 🎯 Призначення: аудит безпеки PHP-версій на серверах
  • 🔍 Методи перевірки: введення URL сайту або прямий запуск на сервері
  • 🛡 Виявлення: критичні вразливості та застарілі збірки
  • 💵 Доступність: для користувачів ШІ-інструментів OpenAI, реліз у жовтні 2026 року
  • Як це працює на практиці: Для проведення аудиту розробникам достатньо передати ШІ-помічнику адресу цільового ресурсу або інтегрувати інструмент у локальне середовище для сканування інфраструктури зсередини.

Автоматизація безпеки: ШІ аналізує відповіді сервера та поведінкові маркери, миттєво вказуючи на наявність застарілого коду, який часто стає мішенню для хакерів.

💡 Думка редакції: Фокус ШІ на кібербезпеці та закритті базових «дір» уlegacy-коді — це надзвичайно практичний крок. PHP досі живить мільйони сайтів, і подібні сканери на базі Codex суттєво спростять життя інженерам із безпеки.
